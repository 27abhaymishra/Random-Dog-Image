
# Random Dog Image Generator  

A simple web application that generates random dog images using a JavaScript API. This project showcases the use of HTML, CSS, and JavaScript to create a fun and interactive experience for dog lovers!  

## Features  

- Fetches random dog images from a public API.  
- User-friendly interface with a button to generate new dog images.  
- Responsive design compatible with various screen sizes.  

## Technologies Used  

- **HTML**: For structuring the web application.  
- **CSS**: For styling and layout.  
- **JavaScript**: For fetching data from the API and managing user interactions.  
- **Dog API**: [Dog API](https://dog.ceo/dog-api/) for retrieving random dog images.
